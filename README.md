# Конструктор цикла

Локальное веб-приложение для расчёта и редактирования программы тренировок по схеме `cycle8.xlsm`.

## Что умеет

- Загружает полный 12-недельный цикл из `cycle8.xlsm` как стартовый шаблон:
  - 12 недель × 3 тренировки × 6 упражнений;
  - 18 упражнений с исходными 1ПМ, коэффициентами `D`/`E` и схемами подходов;
  - прогрессия 1ПМ +1% за неделю (сложный процент).
- Пересчитывает рабочие веса по формуле `MROUND(1ПМ × процент, шаг)`.
- Считает тоннаж, КПШ, средний вес, относительную интенсивность, интенсивность по Фунтикову и время.
- Позволяет менять:
  - упражнения и 1ПМ;
  - количество недель и дней;
  - состав упражнений в каждом дне;
  - подходы, повторы и проценты;
  - прогрессию и разгрузки;
  - округление;
  - коэффициенты метрик.
- Печатает программу и сохраняет PDF через браузер.
- Выгружает Excel: лист «Сводка» и листы недель.
- Делает JSON-бэкап и восстанавливает проект из него.
- Автоматически сохраняет проект в `localStorage` браузера.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://localhost:5173`).

Сборка и проверки:

```bash
npm test
npm run build
npm run preview
```

## Windows: портативный .exe

Windows-сборка не требует Node.js и установки. Соберите её на Linux-машине:

```bash
npm install
./scripts/build-windows.sh
```

Готовые файлы появятся в `release/`:

- `cycle-builder-windows-amd64.exe` — обычные Windows 10/11;
- `cycle-builder-windows-arm64.exe` — Windows on ARM;
- `cycle-builder-windows.zip` — оба файла и инструкция;
- `SHA256SUMS.txt` — контрольные суммы.

Запустите `.exe` двойным щелчком. Приложение поднимет локальный сервер на `http://127.0.0.1:17843` и откроет браузер. Чёрное окно консоли нужно держать открытым — оно останавливает сервер. Данные сохраняются в `localStorage` браузера; фиксированный порт нужен, чтобы сохранения не терялись между запусками. Резервную копию можно сделать в «Настройках» через JSON.

## Как пользоваться

1. Откройте «Упражнения» и введите свои 1ПМ. Веса во всей программе пересчитаются.
2. В «Программе» выберите неделю и меняйте подходы/повторы/проценты. Вес и итоги обновляются сразу.
3. Кнопка «Структура» позволяет добавить день или упражнение, в том числе сразу во все недели.
4. Кнопка «Волна» задаёт процент верхней группы на выбранные недели.
5. В «Настройках» настраиваются прогрессия, разгрузки, округление и коэффициенты.
6. В «Экспорте» выберите область и скачайте Excel или распечатайте программу.

## JSON-бэкап

«Настройки» → «Скачать JSON». Файл содержит упражнения, структуру, схемы, прогрессию и коэффициенты. Импорт заменяет текущий проект после подтверждения.

## Шаблон и расчёты

- Шаблон лежит в `src/data/cycle8.seed.json` и не требует Excel во время работы.
- Эталонные значения xlsm — в `tests/fixtures/cycle8.expected.json`.
- Расчётное ядро находится в `src/domain` и не зависит от React.
- Все 216 строк шаблона сверяются с xlsm в `tests/domain/seedFidelity.test.ts`.

Перегенерировать шаблон из исходного xlsm (dev-only, нужен `openpyxl`):

```bash
/home/UCBerkeley/.venv/bin/python scripts/extract_cycle8.py
```

## Важно

Это инструмент для расчёта тренировочной программы, а не медицинская рекомендация. Перед началом цикла с высокими нагрузками стоит проконсультироваться с врачом и тренером.
